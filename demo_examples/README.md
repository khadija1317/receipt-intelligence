# Demo examples

Four receipts from the CORD dataset (validation split), used as clickable examples in the demo.

- Source: CORD, Hugging Face `naver-clova-ix/cord-v2`. License: CC-BY-4.0.
- The images are re-encoded as JPEG at their original pixel size; nothing else was changed.
- Each `*_ocr.json` is the saved PaddleOCR result for that image. The demo loads it instead of running the OCR, and says so on the page. Every later stage runs live.
